# MoveTalk — Source Analysis & CEFR Curriculum Mapping

## 1. Source A: Official CEFR Framework

**Source:** Council of Europe — Common European Framework of Reference for Languages
**URL:** https://www.coe.int/en/web/common-european-framework-reference-languages
**Access status:** Publicly accessible (no paywall)

### Level Descriptions (can-do statements)

| Level | User type | Core capability |
|-------|-----------|-----------------|
| A1 | Basic | Understand and use familiar everyday expressions; introduce self; ask/answer simple questions; communicate slowly with cooperative speaker |
| A2 | Basic | Understand single sentences on familiar topics; communicate in simple routine tasks; describe background and immediate needs |
| B1 | Independent | Understand main points of clear standard speech; handle most travel situations; produce simple connected text; describe experiences, dreams, hopes |
| B2 | Independent | Understand main ideas of complex text; interact fluently with native speakers; express viewpoints clearly; explain advantages/disadvantages |
| C1 | Proficient | Understand demanding, longer texts; express fluently without searching for expressions; use language flexibly for social, academic, professional purposes |
| C2 | Proficient | Understand virtually everything heard or read; summarize information from different sources; express spontaneously, precisely, with fine nuances |

### Skills tracked separately
- Listening (reception)
- Reading (reception)
- Spoken production
- Spoken interaction
- Written production
- Written interaction

### Assessment approach
- Can-do descriptors (observable statements)
- Not pass/fail; proficiency is a continuum
- Track per-skill, not overall single score
